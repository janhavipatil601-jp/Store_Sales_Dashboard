# Store_Sales_Dashboard
## Project Overview
This project presents an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance and provide meaningful business insights.

## Objectives
- Analyze sales performance and order trends.
- Compare sales across regions and cities.
- Understand product category and sales channel performance.
-Support data-driven business decisions.

## Dashboard Features
- Sales performance visualizations
- Year, region analysis
- Product category analysis
- Monthly sale and profit analysis
- Low performance product analysis

## Skills Demonstrated
- Data cleaning and transformation
- Data visualization
- Interactive dashboard development
- Business and sales data analysis
